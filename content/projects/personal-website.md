A modern personal website and technical portfolio powered by Flask and frozen into static HTML for zero-maintenance hosting.

### Key Highlights
- Clean typographic design with system fonts.
- Built-in Dark / Light mode toggle respecting user preferences.
- Markdown article publishing with YAML frontmatter.
- Pygments syntax highlighting for technical code snippets.
- Automated deployment to GitHub Pages on `git push`.
